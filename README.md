# Cyber Deck terminal prototype

An early Linux terminal interface with a system overview, a module carousel, and up to four embedded interactive shells, one visible at a time. It uses ncursesw for the host display, libvterm for child terminal emulation, and a PTY for each shell's job control. The broader software design is kept outside this repository.

## Install

Run `./install.sh` from this repository to install the packages used by the implemented modules and build Cyber Deck. It supports pacman on Arch/CachyOS, apt on Debian/Raspberry Pi OS Lite, and Termux on Android. On Linux, run it as your normal user; it uses `sudo` only for packages. On Termux it installs the compiler/build dependencies and builds the experimental core TUI without `sudo`. The Linux install includes `nano` for Notes, `elinks` for Web, and `mpv` plus `mpv-mpris` for Wave, along with development libraries for Network, Audio, and Bluetooth. The Linux script installs NetworkManager and BlueZ but does not configure either service; NetworkManager and BlueZ need their services running, and Audio needs a PulseAudio-compatible server.

```sh
./install.sh
```

### Experimental Termux build

Install Termux from its [supported sources](https://github.com/termux/termux-app#installation), clone Cyber Deck into Termux's private home directory (for example, `~/Projects/cyber-deck`), and run `./install.sh`. Do not build from shared storage such as `/sdcard`; Android does not allow programs there to execute normally. The installer uses `pkg` to install `clang`, `cmake`, `pkg-config`, `ncurses`, `libvterm`, `nano`, `elinks`, and `mpv`, then builds `build/cyber-deck`. Run it from Termux with `./build/cyber-deck`.

The Termux build is an experimental core TUI port. Android system settings integration is outside this project's scope. It disables the Linux NetworkManager, PulseAudio, and BlueZ integrations, so Settings → Network, Audio, and Bluetooth are unavailable. Cyber Deck itself uses Termux's terminal and shell. Wave starts the Termux `mpv` package as a child process, so playback, station switching, and stopping stay inside Cyber Deck. This does not create an Android media session, so Android's lock-screen media controls will not appear. `mpv-mpris` is only for Linux desktop media controls. Termux uses Android's Bionic C library and private filesystem paths, so this build is a native Android binary and is not interchangeable with the desktop Linux binary.

On a desktop with `~/.config/hypr/hyprland.local.lua`, `./install.sh` also installs Ghostty on Arch if needed and adds the Cyber Deck shortcut. Use `--desktop` to request this setup explicitly. The build remains at `build/cyber-deck` so it does not replace any other program named `cyber-deck`.

### Manual build

The Bluetooth page uses BlueZ on the system bus and GIO for D-Bus. Install BlueZ and GIO development files to build it (`bluez` and `glib2` on Arch; `bluez` and `libgio-2.0-dev` on Raspberry Pi OS/Debian). If GIO development files are absent, the app builds with Bluetooth marked unavailable. Install `mpv` at runtime to play internet radio in Media > Wave. Install `mpv-mpris` if you want Wave playback to appear in Waybar or another MPRIS client.

Install a C++17 compiler, CMake, ncursesw development files, and libvterm development files using your distribution's package manager. On Arch/CachyOS these are typically `gcc`, `cmake`, `ncurses`, and `libvterm`. On Raspberry Pi OS Lite, use the corresponding Debian packages, usually `g++`, `cmake`, `libncurses-dev`, and `libvterm-dev`. Install `pkgconf`/`pkg-config` and `libnm` development files (`libnm` on Arch, `libnm-dev` on Debian/Raspberry Pi OS) to build the Network page. Install `libpulse` development files (`libpulse` on Arch, `libpulse-dev` on Debian/Raspberry Pi OS) to build the Audio page. Install libcurl development files (`curl` on Arch, `libcurl4-openssl-dev` on Debian/Raspberry Pi OS) for dashboard weather. If an optional library is absent, its page shows unavailable. Package names and availability should be checked on the target system.

```sh
cmake -S . -B build
cmake --build build
./build/cyber-deck
```

Choose another installed shell with `./build/cyber-deck --shell /absolute/path/to/shell`. Otherwise it tries `$SHELL`, the account shell, then `/bin/sh`. Run in an interactive terminal emulator or Linux text console. The embedded child advertises `TERM=xterm`; the host `TERM` remains unchanged.

### Opaque Ghostty window on Hyprland

On this workstation, `desktop/launch-cyber-deck.sh` opens the built app in a separate Ghostty instance using `desktop/ghostty.conf`. It keeps the normal Ghostty settings, but makes this window opaque and starts it at 60 columns by 20 rows. This is the proposed compact grid; some embedded programs need more room. The rule in `desktop/hyprland.local.lua` makes it float, centers it, and places it on a dedicated special workspace. `Ctrl+Super+Alt+Y` opens Cyber Deck once, then hides and shows that same running window; closing Cyber Deck ends the instance. Run `./desktop/install-hyprland-shortcut.sh` once from this repository; it adds the shortcut to the machine-local config so it survives restarts and activates it immediately when Hyprland is running. The launcher can also be run directly from this directory.

## Controls

Cyber Deck opens on Dashboard with terminal 1 already running in the background. Dashboard shows the system overview without a top menu. Use `Alt+h`/`Alt+l` or Left/Right to move through centered three-line glyph titles for Terminal, Media, Notes, Web, and Settings. The glyph display setting provides an ASCII frame, and narrow screens show a plain label when the frame does not fit. Enter opens the selected module's content, except Dashboard, which is already shown at the carousel level. `Alt+Escape` returns to a module preview. `Alt+Escape` on a preview leaves it in place. `Alt+d` returns to the carousel Dashboard. `Alt+t`, `Alt+m`, `Alt+n`, `Alt+w`, and `Alt+s` open the corresponding module content directly. `Alt+s` opens General; other module shortcuts return to the currently selected tab, and `Alt+w` resumes the selected Web tab and any open page. A module shortcut dismisses an open dialog before navigating, except `Alt+n` selects No when a confirmation is open. On the carousel, plain `h`/`l` do not navigate. Inside a panel, arrows perform panel actions. Optional `h/j/k/l` motion is controlled in Settings → General → Navigation. `Alt+h` or Shift+Tab selects the previous top item; `Alt+l` or Tab selects the next. In Terminal and Web, `Alt+l` creates a tab when already on the last one; `Alt+Tab` creates one directly, up to four. Terminal sends Tab and Shift+Tab to the shell. Nano and ELinks receive their plain navigation keys, while Tab and Shift+Tab select Cyber Deck top tabs. The selected tab's content is active immediately. Ctrl combinations remain available to terminal programs. Every screen shows `Shift+Alt+? Help` near the top right; it opens a full-screen `HELP` view with separate `[GLOBAL]` and current-panel or dialog sections. Each shortcut has its own `key: action` entry, arranged in two columns at the 60-column target and three on wider screens. `[GLOBAL]` contains shortcuts that also work while Help or a confirmation is open; navigation keys, Enter, and confirmation choices appear only in the relevant section. Press `Alt+Escape` or the same Help shortcut to close Help. On keyboards where `?` is Shift+`/`, the terminal sends this as Alt+`?`.

Dashboard has four optional instrument-style widgets: Clock, Weather, Network, and Battery. Choose which ones appear under Settings → Interface → Dashboard. The widgets use theme-colored Unicode borders with an ASCII fallback. Clock displays local time and date. Weather shows current temperature in Celsius and a short condition after a city is set under Settings → General → Weather. Enter a city, optionally followed by a region or country to disambiguate it; `r` refreshes it. Weather uses Open-Meteo's [geocoding](https://open-meteo.com/en/docs/geocoding-api) and [forecast](https://open-meteo.com/en/docs) APIs, attributed here under [CC BY 4.0](https://open-meteo.com/en/terms). The free API is for non-commercial use; a commercial deployment needs a suitable Open-Meteo plan or another provider. The city is saved at `$XDG_CONFIG_HOME/cyber-deck/weather-location`, or `~/.config/cyber-deck/weather-location` when `XDG_CONFIG_HOME` is unset. No location or weather request is sent until a city is configured. Weather requests run off the UI thread, each request times out after six seconds, and refresh every fifteen minutes while Dashboard is open. Network shows the WiFi SSID or a connected Ethernet interface, preferring the active default route when both are available. It shows an interface name when NetworkManager cannot provide a connection name; Connected does not establish internet connectivity. Battery shows a charge meter, capacity, and charging state when the system exposes them; a USB power bank without a system battery interface appears as "Not detected." Network and battery refresh every five seconds while Dashboard is open, and the clock updates each minute.

Notes has `[Text]` and `[Voice]` tabs. Text lists `.txt` files in `$XDG_DATA_HOME/cyber-deck/notes`, or `~/.local/share/cyber-deck/notes` when `XDG_DATA_HOME` is unset. The install script installs `nano`; manual builds need it installed separately. Press `n` to name and create a note, use Up/Down (or optional vi motion) to select a note, and press Enter to edit it in an embedded nano session. Nano saves with Ctrl+O and exits with Ctrl+X. Escape goes to nano; `Alt+Escape` returns to the Notes preview while nano keeps running. Reopen Notes to resume it. The Notes editor has its own PTY and does not consume one of the four Terminal slots. Voice has a separate panel; recording and dictation are not implemented yet.

Web starts with `[1]`. `Alt+h`/Shift+Tab move left; `Alt+l`/Tab move right. At the last tab, `Alt+l` creates another, while Tab stays put. `Alt+Tab` creates a new tab directly, up to four. Each Web tab holds an independent ELinks session. `Alt+x` closes the selected Web tab when another tab exists; trying to close the last tab shows a notice. On an empty tab, press `w` for a Wikipedia search, `b` to browse an HTTP or HTTPS URL, `d` for DuckDuckGo search, or `g` for Google search. Enter the query or URL, then press Enter to open results directly in ELinks. DuckDuckGo uses its text-friendly Lite site. Bare domains in Browse use HTTPS. In ELinks, `h` goes back, `j`/`k` select the next/previous link, `l` or Enter opens the selected link, `g` opens a URL, and plain Escape opens its menu. Text fields use a separate keymap, so letters can be typed normally. Use `q` in ELinks to exit the page and return to the empty tab. While ELinks is open, it receives plain keys, including `w/b/d/g`. `Alt+Escape` returns to the Web preview while ELinks keeps running. Cyber Deck hides ELinks' own tab bar and applies a dark palette matching the Cyber Deck theme when a page starts; sites cannot override that palette. The install script installs ELinks; manual builds need it installed separately. Some modern sites, including Google, may render poorly or refuse text-only browsers.

Settings → Apps → Web controls ELinks cookies and page-header links for new Web pages. `Block all` is the default and stops cookie prompts, but sites that require cookies may fail. `Ask` uses ELinks' per-cookie prompts. `Allow for session` accepts cookies silently until that ELinks page exits. `Page header links` controls whether ELinks shows metadata links such as `canonical` and `search` from a page's HTML header; it is off by default. Cyber Deck runs ELinks without loading or saving its browser state to disk. These choices are saved in the Cyber Deck config directory; an existing ELinks page keeps the settings it started with. ELinks cannot identify which cookies are necessary, so none of these modes selectively accepts only necessary cookies.

Media has a `[Wave]` tab with the three default cyber-wave internet stations: Esoterica Radio S3, Nightride FM - Darksynth, and REYFM - LOFI. Enter on the Media preview focuses the station list immediately. Use Up/Down (or optional vi motion) to select a station. Enter starts it, switches to it, or stops it if it is already selected and playing; `s` stops playback. Press `a` to add a station: enter its name, press Enter, then enter a direct HTTP(S) audio-stream URL and press Enter to save. `Alt+Escape` cancels either entry step. The currently playing station has an asterisk. Wave shows `Playing` while the mpv process is active and `Stopped` when it ends or is stopped; stream failures include the mpv exit code when available. `Alt+Escape` returns to the Media preview. Playback needs internet access and `mpv`; it stops when Cyber Deck exits. On Linux, Wave loads `mpv-mpris` explicitly when installed, using the same plugin paths as cyber-wave, and sets the station name as the media title for Waybar and other MPRIS clients. The Termux build plays in Termux without Android lock-screen controls. Added stations are saved in `$XDG_CONFIG_HOME/cyber-deck/wave-stations.txt`, or `~/.config/cyber-deck/wave-stations.txt` when `XDG_CONFIG_HOME` is unset. Cyber Deck keeps this list separate from cyber-wave's configuration.

Enter on the Settings preview opens its content screen on General, with Interface, Devices, and Apps available beside it. Returning to Settings opens General again. Tab/Shift+Tab or `Alt+h`/`Alt+l` moves between these sections. General contains expandable Navigation and Weather sections. Interface contains expandable Theme, Dashboard, and Display sections. Opening one section in a panel closes the other sections in that panel. Use Up/Down to move between section headings and visible options; Enter expands or collapses a heading, applies a theme, or toggles a setting. Fields are indented beneath their section. Values that open a picker or text prompt, including City, WiFi, Audio Output, and Audio Input, appear in brackets. Triangle glyphs show whether a section is expanded. Every module submenu draws its tabs in three-row boxes like the carousel preview. The selected box keeps the normal background and uses theme colors for its border and text. In Greenline, the border is dark green and the text is bright mint. Display → ASCII glyphs changes the box borders to `+`, `-`, and `|`. On narrow screens, the row scrolls to keep the selected box visible. The focused panel heading or option uses the theme highlight. Theme and Web choices use `[x]` and `[ ]` markers. Devices has expandable Network, Audio, Bluetooth, Storage, and Peripherals sections. Use Up/Down to select a heading and Enter to expand it; `1` through `5` jump to their headings. Down focuses expanded content, then moves from Network's WiFi row to Audio, from Audio's Input row to Bluetooth, from Bluetooth's Add device row to Storage, and from Storage's last drive to Peripherals. Network and Bluetooth use centered pickers for their longer inventories; Storage and Peripherals show scrolling lists in the panel. Audio keeps its Output and Input controls in the section. Storage and Peripherals are read-only. `Alt+Escape` steps from a picker to its content, then to its heading, then to the Settings preview. Apps contains Web settings. `Alt+Escape` returns to the Settings preview. In Interface → Theme, choose Husky (white and black), Synthwave (pink, purple, and blue), or Greenline (mint green on a dark background, based on cyber-ware). Expand General → Navigation, then select Vi motion to toggle it; arrows remain available either way. The theme changes Cyber Deck's menus, pages, footer, and the embedded terminal's default text colors immediately; programs that set explicit colors keep them. Display chooses Unicode or ASCII for Cyber Deck’s borders, meters, expand indicators, and decorative icons; embedded terminal programs render their own text. The choice applies immediately and defaults to Unicode. Existing saved UI preferences remain compatible. Theme, vi motion, widget visibility, and glyph mode are saved in the Cyber Deck config directory. The theme is saved in `$XDG_CONFIG_HOME/cyber-deck/theme`, or `~/.config/cyber-deck/theme` when `XDG_CONFIG_HOME` is unset.

In a Settings list, `k` stays on the first item. Press `h` to collapse the focused expanded section and focus its heading. On an Audio volume control, `h` keeps its volume-down action; use Enter on the Audio heading to collapse it. In Devices, Up from a section heading returns to the last item of the expanded section above it. `Alt+Escape` closes a device picker or details window and returns to its section.

Expanded Network shows the connected WiFi name and LAN status without interface names. Enter on the WiFi row opens a centered, scrolling list of wired interfaces and WiFi networks; interface names remain visible there to distinguish wired devices. Expanded Audio shows its server status plus Output and Input controls. Expanded Bluetooth shows its power, status, connected devices, and an Add device row. Enter on Add device opens the centered, scrolling device picker and starts discovery when the adapter is on. “Adapter available” means BlueZ found a local controller; it does not mean a Bluetooth device is connected.

Open Settings → Devices → Network, expand the section, move Down to the WiFi row, and press Enter. In the picker, use Up/Down (or optional vi motion) to select a wired interface or WiFi network. Enter connects it; `d` disconnects, `r` rescans WiFi, and `w` turns WiFi on or off. `Alt+Escape` closes the picker. A wired interface needs a cable and must be managed by NetworkManager. Enter uses an available saved wired profile or creates a default connection when none exists. Static IP and other advanced wired settings still need another tool. WiFi and wired connections can both be active. Press `f` on a saved WiFi network to forget every NetworkManager profile for that exact WiFi SSID; confirm with `Alt+y` or cancel with `Alt+n`/`Alt+Escape`. Forget also disconnects that network if active. Wait for the page to report completion before reconnecting. Saved networks remain listed as "out of range" when no access point is visible, so they can still be forgotten. Enter uses the saved profile directly when one exists; selecting an unsaved personal network opens **PASSWORD MODE**. Press `p` on a saved WiFi personal network to replace an outdated password. All typed letters are password input while password mode is open. The prompt shows PSK or SAE according to the chosen connection method. PSK accepts 8-63 printable ASCII characters or a 64-digit hexadecimal key; SAE accepts any nonempty UTF-8 password up to the input limit of 1024 bytes. Type the password and press Enter to connect or update the saved profile; `Alt+Escape` cancels. Open networks connect directly. Enterprise, WEP, and hidden networks need another setup tool for now. NetworkManager permissions still apply to WiFi changes. Scans and connection attempts run off the UI thread; their progress and failures appear on the page.

The Network picker labels password-protected personal networks with `lock`, so it remains readable in terminals without Nerd Fonts.

Storage lists mounted block volumes as `device: free/total [mount]`, for example `nvme1n1p2: 29G/100G [/]`. Sizes use binary G/M/K units. The `/` row is the root filesystem, not a whole physical drive. Unmounted drives show only total size and `[not mounted]`, since free filesystem space is unavailable until they are mounted. Peripherals lists detected USB devices by their reported product name, or vendor/product ID when no name is provided. Expand either section, press Down to focus its list, then use Up/Down to scroll through every entry. Enter opens a read-only details window for the selected drive or USB device; `Alt+Escape` closes it. Press `r` to refresh. These views use Linux `/proc`, `/sys`, and `statvfs` and do not mount, unmount, or eject devices.

Expand Settings → Devices → Audio and move Down into its content to see the current output and input devices with their volumes. Each volume has a text progress bar when the window is wide enough. `j`/`k` or Up/Down moves between Output and Input. Enter opens a centered, full-screen picker in the current theme; the rest of the interface is cleared while it is open. Use `j`/`k` and Enter to choose the default device, or `Alt+Escape` to return without choosing. The picker scrolls when the list exceeds its visible rows. On the main Audio page, `h`/`l` or Left/Right adjusts the selected default device's volume in 5% steps from 0% to 100%. `Alt+h`/Shift+Tab and `Alt+l`/Tab switch Settings sections. `r` refreshes devices. `Alt+Escape` closes the picker first, then returns to the Audio heading. An asterisk marks the default device in the picker. Monitor sources are hidden from the input picker. This page uses a running PulseAudio-compatible server, including PipeWire's PulseAudio service. Changing the default is handled by the audio server; whether already-playing applications move to the new output depends on its policy. Systems with only ALSA and no PulseAudio-compatible server show Audio as unavailable.

The theme background fills the app. In Ghostty, its window padding supplies the edge spacing, so Cyber Deck uses the full character grid. On a Linux text console or other terminal, Cyber Deck keeps a one-character inset. Content screens place the Help hint in the spacer row below their boxed tabs. CYBER DECK appears at the bottom right. On Terminal, the boxed tabs show only created slots, with the active slot highlighted. Brief notices appear in the footer. Monochrome terminals fall back to bold, dim, and reverse text.

In Ghostty, Cyber Deck also sets the terminal's window background to match Synthwave or Greenline, so Ghostty's pixel padding around the character grid matches the app. It restores Ghostty's configured background when the app exits normally. Other terminal emulators may keep their own padding color; that area lies outside the terminal grid.

Enter on the Terminal preview opens its content screen. `Alt+h` selects the previous existing terminal; `Alt+l` selects the next or creates one at the end. `Alt+Tab` creates a new terminal directly, up to four. Plain Tab and Shift+Tab go to the shell. Closed tabs are compacted when another is created. `Alt+t` opens the current Terminal tab. `Alt+1`, `Alt+2`, `Alt+3`, and `Alt+4` only switch to existing slots; they never create one. Shells keep running while another slot or page is shown. The Terminal boxes omit unused slots, and the spacer row below them shows the Help shortcut at the right.

On Terminal, use `Alt+x` to close the current slot when another terminal exists. Trying to close the last Terminal tab shows a notice. When a shell exits, including after Ctrl+D, its tab closes automatically and Cyber Deck selects another terminal; if it was the last slot, Terminal returns to its preview. `Shift+Alt+?` opens or closes Help, and `Alt+q` quits Cyber Deck. Closing a running slot or quitting with any running shells asks for confirmation. Confirmations, Network password entry, WiFi forget, and Help use centered full-screen screens in the selected theme. Use Left/Right or Tab to choose a button, then Enter to activate it; `h`/`l` also move between confirmation buttons. Destructive confirmations default to No. The underlined `Y` in `[Yes]` means `Alt+y`; the underlined `N` in `[No]` means `Alt+n`. Plain `y` and `n` do not select these buttons. `Alt+Escape` cancels a dialog. Closing the last slot returns to the Terminal preview. Ctrl-C, Ctrl-Z, and Ctrl-] are forwarded to the selected shell's foreground job.

Alt shortcuts require a terminal that sends Alt as an Escape prefix. `Alt+Escape` is Cyber Deck's Back key on every screen. Plain Escape goes to the embedded shell, nano, or ELinks; it does not navigate Cyber Deck on built-in screens. If your terminal reserves an Alt combination or uses a different Meta mode, change its key binding or input mode; console behavior must be checked on the Raspberry Pi.

Ctrl combinations are no longer reserved for menu navigation. While the menu has focus, Enter still opens its selected page; many terminals send the same code for `Ctrl+j` and Enter.

### Bluetooth controls

Open Settings → Devices → Bluetooth, expand the section, move Down to Add device, and press Enter to browse nearby and saved devices. The connected-device list above it is informational; use the picker to manage those devices. `w` turns the adapter on or off. `r` starts or stops discovery; it also refreshes the page if BlueZ was unavailable. Discovery stops after 20 seconds or when you leave the page. In the picker, use Up/Down (or optional vi motion) to select a device. Enter connects a paired device, or pairs and connects a new one. `p` pairs without connecting, `d` disconnects, `t` toggles trust, and `f` asks before forgetting a paired device. `Alt+Escape` closes the picker. Operations report progress or errors without blocking keyboard input. The picker shows the Bluetooth status below the device list, wrapping long BlueZ errors across lines.

Pairing confirmation and PIN/passkey entry appear in a centered dialog. Confirm with Enter on Yes or `Alt+y`; decline with Enter on No, `Alt+n`, or `Alt+Escape`. For PIN/passkey entry, type the code and press Enter. The Bluetooth picker shows text state labels for each device. BlueZ and a system D-Bus service must be running, and the system's Bluetooth permissions still apply. Bluetooth audio devices also need a working PulseAudio-compatible audio server to appear under Audio.

## Current limits

This prototype has a dashboard overview, module carousel, four terminal slots, Network, Audio, and Bluetooth settings pages, a footer, and a spacer row below content menus. It uses Ghostty's pixel padding or a one-character inset on other terminals. Each occupied slot stores up to 500 lines and 2 MiB of scrollback internally, but there is no scrollback viewer yet. The terminal content is capped at 400 columns by 200 rows. The themes use closer palette colors when the host supports 256 colors, and basic color fallbacks elsewhere. Some modified keys, mouse protocols, clipboard protocols, and bracketed paste may be unavailable. Sessions end when Cyber Deck exits; persistence across application exits or Pi-specific tuning is future work. No ARM build or Pi console measurements are claimed here.

The source is separated by responsibility: `terminal.hpp` owns PTY sessions and terminal emulation, `dashboard.hpp` renders the interface, `system.hpp` reads local overview data, `wifi.cpp` integrates NetworkManager for WiFi and Ethernet, `audio.cpp` integrates a PulseAudio-compatible server, `input.hpp` translates keys, `application.hpp` coordinates the event loop, and `platform.hpp` contains terminal-host and signal setup. `main.cpp` only starts the application.

If the app is terminated abnormally and the host terminal looks wrong, run `reset` or `stty sane` in that terminal.

For input troubleshooting, launch with `CYBER_DECK_DEBUG_INPUT=1 ./build/cyber-deck`. The footer shows `INPUT` (host key events received) and `PTY` (key events queued for the shell). These counters help distinguish focus/input problems from shell or application behavior.
